# CASE PICPAY DATA SCIENCE

Este case consiste em 3 notebooks para avaliação de seleção de um conjunto de variáveis e treinamento de um modelo de classificação para risco de crédito. O Notebook 1 traz a análise exploratória e seleção de variáveis usando critérios como qualidade de dados, relaçaõ com o target, usando Information Value e análise de multicolinearidade.
O notebook 2 traz uma análise mais aprofundada sobre as variaveis inicialmente selecionadas e análise da estabilidade relacionada ao target.
Por fim no terceiro e último notebook, é realizada uma análise preliminar usando MLFlow de alguns modelos baseados em árvore (Decision tree e Random Forest) e análise da performance do modelo.
